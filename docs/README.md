# Generic Audio Visualizer system for live audio input

## Requirements
- Compatibility with Rpi OS 64bit on Rpi 5
- Uses Python 3.11 to maintain compatibility with base OS
- Uses OpenGL ES 3.1 to maintain compatibility with base OS
- Operates in self-contained python venv so as not to impact system libraries
- Near realtime visualization of micrphone audio
- Ability to hotswap visual presets
